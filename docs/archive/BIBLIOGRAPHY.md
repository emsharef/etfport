# Bibliography

One row per source. `status` is `text` when the full text is in `refs/text/<key>.md`, `wanted` when the
lab needs it and cannot fetch it — the human supplies those — or `cited` for a standard textbook whose
full text is not needed: any ledger entry depending on it states the result as textbook-standard with
the theorem number (AGENTS.md rule 21), rather than quoting the book verbatim.

Register with `ops/refs-fetch.sh <doi-or-url> <key>`, or `ops/refs-import.sh <pdf> <key> "<citation>" [doi]`
for a file, or `ops/share.sh import ...` from the share folder.
