# Citation

For a mathematical result, cite *When Forecasts Change: Rebalancing Active
Funds and ETFs*, the version dated 2026-10-02, and the numbered result.
The broader research record is *Quarterly portfolio construction with uncertain
alpha and factor premia*, archived from the lab's 2026-09-30 source.
These are research drafts, not journal publications. The manuscripts do not
supply an author line or DOI; do not invent one from the software metadata.

For software, numerical inputs or proof artifacts, also cite the release and commit:

```bibtex
@misc{etfport_software,
  title = {ETFPort: portfolio allocation across active funds and ETFs},
  year = {2026},
  howpublished = {\url{https://github.com/emsharef/etfport}},
  note = {Version 0.1.0; repository commit: INSERT-COMMIT}
}
```

A GitHub release is not a permanent DOI-backed archival deposit. That deposit
remains an outstanding manuscript publication requirement. The complete
[reference registry](docs/archive/BIBLIOGRAPHY.md) resolves literature keys
used in the preserved sources; it is provenance, not a claim that every entry
is cited in the edited article.
