## 0.1.0 — 2026-10-05

- Installable Python API and CLI for funded one-review and two-review allocation.
- Predictive-moment construction with separate alpha and premium uncertainty.
- Policy comparisons, directional costs, caps and probability-normalized funding diagnostics.
- Eleven manuscript examples covered by numerical regression tests.
- Standalone manuscript, full lab paper, editable sources and five current figures.
- Original Lean sources, proof map, numerical studies and source provenance.

The Python implementation is numerical, not machine checked. Examples use
assumed inputs and the article's additive quarterly score; no empirical
performance claim, new theorem or general long-horizon policy is added.
