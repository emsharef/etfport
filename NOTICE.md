# Licensing and source attribution

The MIT license covers the original Python software, Lean source and release
guides. It does not relicense the manuscripts and their figures, third-party
dependencies or source documents. The manuscripts are supplied for reading
and scholarly citation; no separate reuse license is granted for their text
and figures.

Numerical inputs distributed here are assumed research inputs, not a licensed
market dataset. Third-party full-text research articles, the literature PDF
collection, local credentials, agent configuration and lab scheduling tools
are not included. Literature attribution in source comments and manuscript
bibliographies is retained.

The Lean project retains its original internal Lake package name, `lab`.
It has no scheduler functionality. Mathlib and Lean dependencies are obtained
separately at pinned revisions, and their own licenses apply.

The public Python API is a release implementation of the finite allocation
programs. It is validated against the preserved numerical studies; it is not
itself machine checked. Source provenance and verification scope are documented
in `docs/source-snapshot.json` and `docs/formalization.md`.
